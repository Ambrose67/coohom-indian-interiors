# Which Coohom features need which plan

From coohom.com/pricing and Help Center articles, read November 2026. Prices and limits change: check the pricing page before quoting a client. If a tool is locked on the user's account, tell them which plan the page lists for it; never work around a lock.

| Feature | Basic (free) | Pro | Elite | Enterprise |
|---|---|---|---|---|
| Design projects | up to 3 | unlimited | unlimited | unlimited |
| Floor planner, walls, doors/windows, model library | ✓ (standard catalogue) | ✓ (premium catalogue) | ✓ | ✓ |
| Renders | 1K, low-res, watermarked | unlimited 4K; monthly 8K and video quotas | annual 8K / 1080p video quotas | by contract |
| 360° walkthrough | normal quality, 2K | + 8K panorama, 720° VR tour | ✓ | ✓ |
| Custom modeling tool (Freeform / custom modelling) | ✗ | ✓ | ✓ | ✓ |
| BOM download | ✗ | ✓ | ✓ | custom quotation/BOM export |
| Download construction drawings and floor plans | ✗ | ✗ | ✓ | ✓ |
| Floor plan drawing download (Help Center) | — | — | Elite only for personal users | ✓ |
| Export to CAD | ✗ | ✗ | ✓ | ✓ |
| 3D presentation (interactive share link) | ✗ | ✗ | ✓ | ✓ |
| Team collaboration / team library | ✗ | ✗ | ✓ | ✓ |
| Custom Furniture Drawings (cabinet annotation drawings, CAD download) | ✗ | ✗ | 5 free trials | ✓ |
| Kitchen & Bath parametric model editor, K&B construction drawings, K&B JSON/XML export and order management | ✗ | ✗ | ✗ | ✓ |
| AI tools | — | "AI tools" / AI rendering mentioned | — | AI allowance set in contract |
| Personal model library slots | 10 | 100 | 2000 | — |

Credits: credits included with a membership expire at the end of each billing cycle; separately purchased credits do not expire. Live Render shows remaining credits and time under **Top Up**.

Prices seen in November 2026 (INR): Pro ₹28,900/year (₹2,890 monthly), Elite ₹64,000 per seat per year (₹6,400 monthly), Enterprise on request.

Where the pricing page and what an account actually shows disagree (accounts sometimes have trials or legacy access), go by the account and say so.
