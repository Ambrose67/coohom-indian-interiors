# Sources and confidence

How the numbers in this skill are grounded, so an agent knows how far to trust them.

| Kind of value | Basis | How to treat it |
|---|---|---|
| Room minimums, stair rules, door/window norms | National Building Code of India 2016 Part 3 and common Indian practice | Check the current code and local rules (TNCDBR 2019 in Tamil Nadu; Kerala Panchayat / Municipality Building Rules 2019) for approval drawings |
| Body dimensions, counter/reach heights | Published Indian anthropometric averages as summarised in practice guides | Use the client's actual heights when known |
| Kitchen, wardrobe, unit sizes | Common Indian modular practice (factory modules and site carpentry in Tamil Nadu and Kerala) | Typical values; site measurements override |
| Plywood grades | IS 303 (MR/BWR) and IS 710 (marine/BWP) | Check the IS mark on delivery |
| Sheet sizes, edge band, kerf, trim | Common workshop practice | Set kerf and trim to the actual saw |
| Hardware sizes (pull-outs, baskets, slides, corners) | Manufacturer catalogues (e.g. Hettich, Vauth-Sagel, Kaff list oil/bottle pull-outs for 150/200/300 cabinets) | Always (check catalogue) for the chosen model |
| Unit counts per 1BHK/2BHK/3BHK/villa, loft split rules, island depth, landing space, top rail width, shutter gaps | Practice conventions | Marked (rule of thumb); adjust to the family |
| Coohom menu names and steps | Coohom Help Center (coohom.com/helpcenter) and beginner lessons, read November 2026 | UI changes often — confirm with a screenshot |

Not confirmed from Coohom documentation: a dedicated section-view tool, a plywood cut list / panel list export, and a separate "wall unit" or "corner unit" article. The skill says so where relevant.

"GTPT" is used by some Indian vendors for their tandem drawer / basket sets; it is not a standard term — confirm what a supplier's "GTPT" set includes.
